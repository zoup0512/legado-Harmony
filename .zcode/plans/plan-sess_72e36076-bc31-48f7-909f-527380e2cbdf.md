## Context
当前 App 存在固定阅读统计、假阅读记录、演示笔记，以及只提示成功但不执行业务的入口。此次按前述建议做一轮“去伪功能”：让当前可达界面只呈现真实能力，不补造新的统计、同步或规则引擎。

## 实施范围
### 1. 个人中心收敛
- `entry/src/main/ets/pages/view/myCenter/MyCenter.ets`：移除固定昵称/假账号登录区、今日阅读、读过/读完/书签/勋章统计，以及无效设置、夜间、备份、净化、Web服务、帮助、清缓存、文件管理入口。
- 保留并合并为清晰列表：**隐私文件夹、主题、关于我们**。书源真实管理继续从发现访问；服务器配置继续从服务器书架访问。
- 保留当前未提交的隐私入口置首和专用锁图标。
- `MyThemeConfig.ets` 撤掉桌面图标、启动页空 Tab；保留真实主题选择、新建和删除。关于页仅撤空链接/开发人员/崩溃日志操作，保留应用市场、版本日志、合规页；修正现有QQ群弹层取消关闭行为。

### 2. 去掉假阅读数据与无效操作
- `BookDetailPage.ets`：移除固定类型/完本/字数、阅读时长/天数/次数、样例笔记、永久加载的“书源24”和无效分享图标。作者、简介仅显示真实值或中性空态。
- 保留真实目录、立即阅读、实际加书架和服务器本地缓存链路。
- `shareWorksBook.ets` 只保留真实“保存图片”，撤掉微信/QQ/系统分享/导出/链接及链接有效期；清理分享卡片的固定元数据。
- 书单预览撤掉只弹“已加入书架”的按钮，保留真实书单增删改、推荐理由和图片保存，不扩大到共享 DAO 改造。
- 分组管理撤掉无持久化的拖动排序；文件夹撤掉没有提醒业务的“更新提醒”。不删除对应数据库字段。
- 演示笔记组件清空样例与假保存动作，避免旧引用继续暴露假数据；不重构旧阅读器。

### 3. 搜索、书源与订阅清理
- `SearchBook.ets` / `SearchHistory.ets` / `SearchDetails.ets`：用中性搜索提示替代假历史，撤空筛选和只延时结束的假刷新；保留真实搜索、类型切换及搜索进度。
- `ImportCommon.ets` / `SubscriptionImport.ets`：撤下标奇偶生成的“正在使用”和未参与导入判断的保护勾选；保留真实已有/新增/更新比较、分组、多选和入库。
- `Find/BookSource/components/SourceView.ets` / `AddSourcePage.ets`：移除空校验、导出、执行登录、调试、源码查看和分享入口。同步调整菜单分发，避免删除菜单项后索引错位。
- `SubscriptionIndex.ets`：批量操作只保留真实删除；撤空移动、分享、导出。分组菜单撤假重命名/置顶，以及没有整组处理逻辑的移动动作；保留单项真实编辑、置顶、移动、删除。
- 保留发现真实刷新、订阅收藏及最近使用清空，不按“有动画/有定时器”一刀切。

### 4. 修复已有功能的明确 bug
- `database/dao/BookSourceDao.ets`：评分排序从误用 `bookSourceGroup` 改为按现有 `CAST(bookSourceScore AS REAL)` 降序；时间和默认排序保持不变。
- 复用现有评分字段和写入逻辑，不新增表、字段或迁移。

### 5. 路由和清理边界
- `resources/base/profile/main_pages.json`：移除已整体下线且确认无其他有效入口的演示页面注册，包括统计、旧设置、云盘/WebDAV、缓存清理、文件管理、帮助及演示下载管理；同时撤掉其可达跳转。
- 演示页源码可暂留不注册、不导入；仅清理此次变更产生的无用 import、状态、空布局。不开展旧阅读库或 Web 工程大规模删除。
- 不删除用户书籍、书源、订阅、隐私数据和旧偏好；不改签名或构建配置；不提交或推送。

## 验证
1. 静态检查所有撤掉入口的引用和路由，检查菜单索引与残留假数据；执行 `git diff --check`。
2. 给评分排序补针对性回归验证，覆盖分组名与评分顺序不一致、文本评分及空评分；优先使用现有 Hypium/数据库测试基础，测试数据仅写独立测试存储。
3. 使用 DevEco 自带 Node/hvigor 执行 `assembleHap`，先按当前配置确认正确 target，不为构建方便改用户已有签名/target。若环境或原有配置阻塞，记录实际错误，不报告为编译通过。
4. 有可用鸿蒙设备时验证：个人页无假统计；详情无假记录；搜索和导入仍可用；评分排序正确；书源评分/分组/启禁用、订阅删除/置顶/收藏、书单图片保存、本地阅读和隐私入口不受影响。无设备则明确标注未完成运行验收，不以 Android 模拟器代替。

## 交付
提供按模块的变更清单、保留的真实功能、评分排序修复结果，以及构建/测试通过项与未验证项。
